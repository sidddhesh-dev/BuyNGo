BuyNGo is a full-stack e-commerce web application built using Django, HTML, CSS,Java Script , Python , SQL ,JSON and  DjangoRest Api  designed to provide a smooth and modern product browsing experience. The application integrates a third-party product API to automatically fetch product data and store it in a local database for improved performance and scalability.
BuyNGo demonstrates how to build a scalable e-commerce platform by combining backend logic, API integration, and frontend rendering. It focuses on efficient data handling by minimizing repeated API calls through local database storage.
Backend: Django (Python)
Frontend: HTML5, CSS3 ,Javascript
Database: SQLite (default Django DB)
API: Third-party REST API
